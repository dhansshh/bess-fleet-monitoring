Contractual availability

A = (T − Dcounted − Dexcused) / (T − Dexcused)

T = period block-hours. Each block and 15-min interval gets one state, so overlapping tickets are never double-counted. Priority: grid curtailment, then unplanned fault, then planned maintenance.

Contract rules applied

  • TSO curtailment is excused in full.
  • Planned maintenance is excused up to 72 h per block per year; hours beyond the allowance count.
  • Guarantee 97.0 % (DE sites) and 97.5 % (NL site), measured monthly.
  • LD rate €450 per MW per %-point of monthly shortfall.
All telemetry, tickets, prices and contract terms are simulated for this portfolio project and do not describe any real asset. Code: Python (pandas, NumPy), SQLite, SQL views, vanilla SVG.
